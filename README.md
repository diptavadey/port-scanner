# 🔍 Port Scanner

A lightweight, fast, and extensible port scanner built for developers, security enthusiasts, and network engineers who want clear visibility into open ports and services on a target system.

---

## ✨ Overview

This project is a simple yet powerful **port scanning tool** that allows you to probe a host (IP address or domain) and identify open, closed, or filtered ports. It is designed with performance, clarity, and usability in mind—making it ideal for learning, testing, and small-scale security audits.

---

## 🚀 Features

* ⚡ **Fast scanning** using efficient socket handling
* 🎯 **Custom port ranges** (scan specific ports or full ranges)
* 🌐 **Supports domains & IP addresses**
* 📊 **Clear output formatting** for quick interpretation
* 🧵 Optional **multi-threading** for improved speed
* 🔍 **Service detection (basic)** for known ports
* 🛠️ Easy to extend and customize
